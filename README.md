# ViaVerse newsletter

Personal daily newsletter: greeting, CAT countdown, quote of the day, three picks (startup, finance, AI explainer) and a CAT vocab quiz.

- `issues/<date>/email.html`: the full email HTML (images load from `img/`)
- `issues/<date>/content.txt`: researched picks, links and vocab answers
- `img/`: softened background and logo images
